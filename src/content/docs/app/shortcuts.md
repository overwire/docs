---
title: Keyboard shortcuts
description: Every keyboard shortcut in the Overwire desktop app.
---

Shortcuts are suppressed while focus is in a text field, so typing never triggers them. On Windows (when that build ships) every ⌘ below is Ctrl — the bindings already accept either.

## Navigation

| Shortcut | Action |
| --- | --- |
| ⌘1 | Explorer |
| ⌘2 | Workbench |
| ⌘3 | History |
| ⌘4 | Pull Requests |
| ⌘5 | Repository |
| ⌘, | Settings |
| ⌘O | Open Project… |

## Runs

| Shortcut | Action |
| --- | --- |
| ⌘. | Cancel the active run |
| ⌘J | Toggle the bottom runs panel |
| Esc | Close the bottom panel |

## Appearance

| Shortcut | Action |
| --- | --- |
| ⇧⌘T | Cycle theme (dark → system → light) |

The standard macOS application shortcuts (⌘Q quit, ⌘W close window, ⌘M minimize, copy/paste) all behave normally.
